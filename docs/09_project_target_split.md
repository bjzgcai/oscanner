OScanner 功能聚焦讨论

现在 OScanner 里有多个功能点，职责是不清晰的，每个工具应该只做自己的事情，不要加入其他工具的功能，类似 Unix 的工具

## 用户数据生产者

三个独立的工具：以用户为key，跑不同的子工具，往数据库里吐用户的不同类型评测的数据

* 成长轨迹
	* checker：对标的是 agent 开发里的 tools 的能力
* 测试运行器+PQ
* 数据生产工具

设计 <工具，用户> -> 通用数据结构

## 用户数据的展示

* 千帆竞发（读数据可视化）
	* 这个是和具体工具以及课程应该解除耦合的，课程能用，任意一组仓库repo通过工具产生的数据也应该能用
	* 复用之前的工具，约定好输入输出数据格式（需要一个数据格式文档放 docs 目录下）

## 结论：OScanner 目标聚焦

1. 只做扫描，和其他工具的集成，应该是另外一个事情（PQ和千帆竞发不应该在这里展示）
2. OScaner的数据只关心自己的数据写数据库，数据怎么消费是其他工具的事情
3. 课程也是自己独立的数据
